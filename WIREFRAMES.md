## 🎯 **Key Design Principles**

1. **Clean & Minimal**: Focus on the 3D content, not the UI
2. **Touch-Friendly**: Large buttons and touch targets for mobile
3. **Progressive Disclosure**: Show only what's needed when needed
4. **Consistent Navigation**: Clear back buttons and breadcrumbs
5. **Visual Hierarchy**: Important actions are prominent
6. **Responsive**: Works on desktop, tablet, and mobile
7. **Accessibility**: High contrast, readable fonts, keyboard navigation

## 🎨 **Color Scheme**

- **Primary**: Blue (#3b82f6) - Actions, links, highlights
- **Secondary**: Gray (#64748b) - Text, borders, subtle elements
- **Background**: Light gray (#f8fafc) - Page backgrounds
- **Cards**: White (#ffffff) - Content containers
- **Success**: Green (#10b981) - Success states
- **Warning**: Yellow (#f59e0b) - Warnings
- **Error**: Red (#ef4444) - Errors, destructive actions

## 📐 **Layout Specifications**

- **Max Width**: 1200px for desktop
- **Grid**: 12-column responsive grid
- **Spacing**: 8px base unit (0.5rem)
- **Border Radius**: 8px for cards, 4px for inputs
- **Shadows**: Subtle drop shadows for depth
- **Typography**: Inter font family, 16px base size
